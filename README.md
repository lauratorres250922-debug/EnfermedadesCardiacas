## Problema de negocio
Una red de clínicas cardiológicas quiere entender qué variables clínicas están más asociadas con la presencia de enfermedad cardíaca, y cómo debería "actualizar" su sospecha diagnóstica a medida que llegan resultados de distintas pruebas. Este repositorio contiene el análisis probabilístico realizado desde el rol de analista de datos para esa red de clínicas, aplicando 11 conceptos fundamentales de probabilidad y teoría de la información sobre datos clínicos reales.


## Dataset
Heart Disease Dataset (UCI Machine Learning Repository, base de Cleveland) 297 pacientes (tras limpieza de valores faltantes), 14 atributos clínicos —edad, sexo, tipo de dolor de pecho, colesterol, frecuencia cardíaca máxima, entre otros— y variable objetivo de presencia de enfermedad cardíaca.
Fuente: https://archive.ics.uci.edu/dataset/45/heart+disease

Archivo usado: processed.cleveland.data
